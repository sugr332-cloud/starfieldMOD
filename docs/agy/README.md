# agy 運用ルール（指示書と報告のやり取り）

このフォルダは、Claude（計画・レビュー担当）と agy（実作業担当）が、ユーザーを介した長文のコピペなしでやり取りするための場所です。

## 流れ

1. Claude が指示書を `docs/agy/<フェーズ名>.md` として main にpushする
2. ユーザーが agy に「docs/agy/<フェーズ名>.md を読んで実行して」と伝える
3. agy は main を pull して指示書を読み、作業する
4. agy は報告を `docs/agy/reports/<フェーズ名>-<連番>.md` に書き、作業ブランチに commit・push する
5. ユーザーが Claude に「報告来た」と伝える
6. Claude はブランチの報告を読み、OK なら次の指示を、修正が必要なら指示書の更新をpushする
7. ユーザーが agy に「OK、続けて」または「指示書が更新された。読み直して」と伝える

ユーザーが agy の報告や Claude の指示を貼り付ける必要はありません。

## agy が止まる場面（この3つだけ）

以下に当たるときは、実行する前に報告ファイルを push して止まり、ユーザーの「OK」を待つこと。

1. **元に戻せない操作**: ファイルやフォルダの削除、セーブデータへの書き込み、ゲームフォルダ直下へのファイル配置、INI の変更（バックアップ前）
2. **ゲームの起動**
3. **仕様・指示書にないこと**: 仕様（docs/MOD_SPEC.md）や指示書と食い違う、書かれていない判断が必要、前提が満たされていない

それ以外の、仕様と指示書の範囲内の作業は、止まらずに進めてよい。ただし、何をしたかは報告ファイルにすべて記録すること。

## 常に守ること

- docs/MOD_SPEC.md の14章（禁止事項）を守る
- ブラウザの履歴・Cookie・パスワード・アカウント情報など、個人データには一切アクセスしない
- Nexus Mods 等へのログイン・アカウント操作をしない
- APIキー・個人のパス・ユーザー名をリポジトリに書かない（<Starfield>、<MO2>、<Documents>、<Steam> のように伏せる）
- 指示書にないファイル・MOD・モデルのダウンロードをしない
- commit・push してよいのは、作業ブランチへの `docs/agy/reports/` 配下の報告ファイルだけ。それ以外のファイル（docs/、configs/、tools/ など）の commit・push と、main への push・マージは、Claude の確認後に指示書で指示されたときだけ行う

## 報告ファイルの書き方

`docs/agy/reports/<フェーズ名>-<連番>.md`（例: `phase1-core-01.md`）

```
# <フェーズ名> 報告 <連番>

- 日時:
- 状態: 停止中（OK 待ち）/ 進行中 / 完了
- 停止した理由: （止まる場面の 1〜3 のどれか。完了なら「完了」）

## 実施したこと

## 確認した事実

## 次にやること（OK が出たら実行すること）

## 問題・仕様との食い違い
```
