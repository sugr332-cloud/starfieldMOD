## ユーザーの決定

AI 会話（AISS + LM Studio）はやめる。以後は AI なしの MOD 構成だけで遊ぶ。

## 方針

- MOD やツールのファイルは**削除せず残す**（後で再開したくなった場合にすぐ戻せるように）。使わない状態にするだけ
- 起動はデスクトップのアイコン1つにまとめる

## 作業1: 起動アイコンの整理（止まらずに進めてよい）

- 「Starfield（AIなし）」を「**Starfield（MOD）**」に改名する（中身は Stable-NoAI プロファイルで SFSE を起動、LM Studio・中継・AISS Backend は起動しない）
- 「Starfield（AIあり）」と「AISS 状態確認」のアイコンはデスクトップから削除する（ランチャーや診断ツールのファイル自体は残す）
- LM Studio・中継（llm-proxy）・AISS Backend が Windows の起動時などに自動で立ち上がる設定があれば無効にする（LM Studio のログイン時のサーバー自動起動など）。プロセスが動いていれば終了する

### LM Studio を完全にオフにする（ユーザーの明示的な要望: VRAM を使いすぎるため）

- 読み込まれているモデルをすべて取り外す（`lms unload --all` 等）
- LM Studio のローカルサーバーを停止する（`lms server stop`）
- LM Studio アプリ本体（バックグラウンド・タスクトレイ常駐を含む）を終了する
- LM Studio の設定で、Windows ログイン時の自動起動・サーバーの自動起動・バックグラウンド常駐（ウィンドウを閉じても動き続ける設定）を**すべて無効**にする
- タスクマネージャーで LM Studio 関連のプロセス（llama-server 等を含む）が残っていないこと、GPU の専用メモリ使用量が下がったことを確認し、前後の数値を報告する
- LM Studio のアンインストールやモデルファイルの削除はしない

  - 案A: Stable のセーブを Stable-NoAI にコピーして続きから遊ぶ（AISS の残りデータが残るが、多くの場合は問題なく動く。不具合が出たら案Bへ）
