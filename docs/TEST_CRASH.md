# ニューゲーム開始時フリーズの切り分けテスト手順書

ニューゲーム（NEW）開始直後の PC フリーズ（画面暗転・操作不能）の原因を特定するためのテスト手順です。  
**上から順に実施し、フリーズした時点でテストを中止して結果を伝えてください。**

---

## テスト前の共通準備

テストを行う前に、VRAM やメモリを圧迫する常駐アプリをすべて終了してください：
- ブラウザ（Edge, Chrome 等）
- Discord
- その他ゲーム・クライアント（WardogsClient 等）

---

## 切り分けテスト手順（順番に実施）

### テスト 1: LLM なしで NEW
1. デスクトップのショートカット**「Starfield（MOD・LLMなし）」**をダブルクリックして起動します。  
   ※LM Studio のモデルを読み込まず、AISS Backend と SFSE だけが起動します。
2. ゲームのメインメニューが表示されたら、**「NEW」**を押します。

- **結果の判定**:
  - **フリーズせずキャラメイクに進めた**:  
    → 原因は **VRAM の競合・枯渇（LLM 常駐によるメモリ不足）** の可能性が極めて高いです。テストはここで終了です。
  - **フリーズした（PC が止まった）**:  
    → 電源ボタン長押し等で PC を再起動し、**テスト 2** へ進んでください。

---

### テスト 2: LLM なし・Alternate Start なしで NEW
※テスト 1 でフリーズした場合のみ実施します。

1. Mod Organizer 2（MO2）を開きます。
2. 画面上部の「プロファイル」ドロップダウンから**「Test-NoAltStart」**を選択します。  
   （※Roleplayers' Alternate Start だけが無効化された切り分け用プロファイルです）
3. MO2 の実行ボタンから**「SFSE」**を選択して実行します。
4. メインメニューで**「NEW」**を押します。

- **結果の判定**:
  - **フリーズせずゲームが開始した（鉱山シーン等に進めた）**:  
    → 原因は **Roleplayers' Alternate Start**（またはその前提スクリプト）です。
  - **フリーズした（PC が止まった）**:  
    → 電源ボタン長押し等で PC を再起動し、**テスト 3** へ進んでください。

---

### テスト 3: MOD なし（バニラ）で NEW
※テスト 2 でもフリーズした場合のみ実施します。

1. MO2 やランチャーを使わず、**Steam から直接普通に Starfield を起動**します。
2. メインメニューで**「NEW」**を押します。

- **結果の判定**:
  - **問題なく起動した**:  
    → MOD 構成（SFSE プラグインやコア環境）に問題があります。
  - **これでもフリーズした**:  
    → MOD ではなく、Starfield ゲーム本体のインストール状態、グラフィックドライバ、またはハードウェア環境側の問題です。

---

## 結果の報告方法

テストが完了（または中断）したら、何番のテストでどのような結果になったかを Claude に伝えてください。
